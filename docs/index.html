An LLM-orchestrated pentest harness.

A ReAct agent (LangGraph) decides which security tools to call against an authorized target — with a hard scope guard, a kill-switch budget, and dry-run by default standing between the model and the network.

hackbot demo --dry-run
▶ quickstart ⛨ safety model ★ view source ↗
⚠ AUTHORIZED USE ONLY — point hackbot only at systems you own or have written permission to test. If a target isn't in scope.json, every network tool hard-fails with a ScopeViolation.

what is this

A harness, not a weapon. The LLM plans; the guards decide what is allowed to leave the machine.

agent-driven

The model gets the tool list via bind_tools and picks what to call at each step — recon, secret scans, findings.

scope-locked

Every network tool calls check_target first. Host globs + CIDRs + path rules. Out of scope = hard fail.

budgeted

Caps on steps, total requests, and tokens. A kill switch stops the session cold at the request ceiling.

dry-run first

By default, tools return "would-send" and touch nothing. Going live is an explicit opt-in.

the react loop

agent → tools → agent → … → report. It ends on finish, on an exhausted budget, or when the model has nothing left to call.

safety model

None of these can be talked around by the model. They live in code, below the agent.

guardwhat it does
scope guardcheck_target runs before any I/O: host glob + CIDR, allowed paths, excluded paths. Violation → ScopeViolation.
kill switchHard-fails once request_count ≥ max_total_requests, independent of the soft budget.
dry-runDefault on. Network tools simulate instead of sending.
authorizationrun refuses to start unless scope.authorized_by is set.
budgetSteps / requests / tokens capped; exhaustion routes straight to the report.
no destructive payloadsThe system prompt forbids DROP, rm -rf, shutdown, fork bombs; prefers reads over writes.
no wildcard hostallowed_hosts cannot be a bare "*".

quickstart

Smoke-test with no API key and no network, then verify scope, then go live on an authorized target.

# 1. install (pip or uv)
pip install -e ".[dev]"
# no pip? → uv venv .venv && source .venv/bin/activate && uv pip install -e ".[dev]"

# 2. run the full ReAct loop with a fake LLM — no key, no network
hackbot demo --dry-run

# 3. sanity-check your scope (exit 0 = OK, exit 1 = VIOLACAO)
hackbot check-scope http://localhost:3000 scope.json
hackbot check-scope http://evil.com       scope.json

# 4. configure a model
cp .env.example .env    # set PH_OPENAI_API_KEY=sk-...

# 5. dry-run against a real target (still sends nothing)
hackbot run --target http://localhost:3000 --scope-file scope.json --dry-run

# 6. go live — only on an authorized target
hackbot run --target http://juice-shop.lab --scope-file scope.json --no-dry-run --output report.md

tools the agent can call

Six tools. The network-facing ones are scope-guarded and dry-run aware.

toolscope?purpose
check_scope(url)—Validate a URL against the scope. Called first.
http_probe(url, method, headers, body)✅HTTP request. GET/HEAD/OPTIONS/POST/PUT/PATCH. Rate-limited.
scan_js_bundle(url)✅Download JS and scan for secrets, cards, exfil patterns.
analyze_text_for_secrets(text)—Local regex: AWS keys, sk- keys, JWTs, cards, private keys.
save_finding(title, severity, evidence, url)—Record a finding (CRITICAL/HIGH/MEDIUM/LOW/INFO).
finish(reason)—End the loop and trigger the report.

any model you like

OpenAI + Anthropic natively; any OpenAI-compatible endpoint (DeepSeek, GLM/Zhipu, local) via PH_LLM_BASE_URL.

# DeepSeek (OpenAI-compatible)
export PH_LLM_PROVIDER=openai
export PH_LLM_MODEL=deepseek-chat
export PH_LLM_BASE_URL=https://api.deepseek.com/v1
export PH_OPENAI_API_KEY=sk-...

# Anthropic
export PH_LLM_PROVIDER=anthropic
export PH_LLM_MODEL=claude-3-5-sonnet-latest
export PH_ANTHROPIC_API_KEY=sk-ant-...
